# Dev Container Features: sugoi-wada

このリポジトリは [dev container Features](https://containers.dev/implementors/features/) のコレクションです。
[Feature 配布仕様](https://containers.dev/implementors/features-distribution/)に従い、GitHub Container Registry で公開しています。

## 収録している Feature

### `google-cloud-sdk`

Google Cloud CLI（`gcloud` / `gsutil` / `bq`）をインストールします。

```jsonc
{
    "image": "mcr.microsoft.com/devcontainers/base:ubuntu",
    "features": {
        "ghcr.io/sugoi-wada/devcontainer-features/google-cloud-sdk:1": {
            "version": "latest",
            "components": "gke-gcloud-auth-plugin,kubectl"
        }
    }
}
```

| Option | 説明 | 型 | 既定値 |
| --- | --- | --- | --- |
| `version` | インストールするバージョン（`latest` または `583.0.0` のような具体的なバージョン） | string | `latest` |
| `components` | 追加インストールするコンポーネント（カンマまたは空白区切り） | string | `""` |

インストール方式や `components` の指定方法の詳細は
[`src/google-cloud-sdk/NOTES.md`](src/google-cloud-sdk/NOTES.md) を参照してください。

## リポジトリ構成

各 Feature は `src/<feature-id>/` 配下に `devcontainer-feature.json` と `install.sh` を持ちます。

```
├── src
│   └── google-cloud-sdk
│       ├── devcontainer-feature.json
│       ├── install.sh
│       ├── NOTES.md
│       └── README.md
├── test
│   ├── _global
│   │   ├── all_the_clis.sh
│   │   └── scenarios.json
│   └── google-cloud-sdk
│       ├── scenarios.json
│       ├── test.sh
│       └── ...
└── .github/workflows
    ├── test.yaml       # CI（自動生成テスト / シナリオテスト / グローバルテスト）
    ├── validate.yml    # devcontainer-feature.json のバリデーション
    └── release.yaml    # GHCR への公開とドキュメント生成
```

## テスト

[`@devcontainers/cli`](https://github.com/devcontainers/cli) を使ってローカルでテストできます。

```bash
npm install -g @devcontainers/cli

# ベースイメージごとの自動生成テスト
devcontainer features test --skip-scenarios -f google-cloud-sdk -i mcr.microsoft.com/devcontainers/base:ubuntu .

# シナリオテスト（オプションの組み合わせ）
devcontainer features test -f google-cloud-sdk --skip-autogenerated --skip-duplicated .

# グローバルシナリオ
devcontainer features test --global-scenarios-only .
```

## 公開

`release.yaml` ワークフローを `workflow_dispatch` で実行すると、`src` 配下の Feature が
`ghcr.io/sugoi-wada/devcontainer-features/<feature-id>` として公開され、README が自動生成されます。

公開後は Feature を private から public に切り替える必要があります
（GHCR のパッケージ設定 → Change Visibility）。
